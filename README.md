# Dad Joke Showdown

[![make.fun](https://make.fun/badge/u-mfnakmal-dad-joke-showdown-1d2ce3e5.svg)](https://make.fun/competitions/u-mfnakmal-dad-joke-showdown-1d2ce3e5)

A single one-line dad joke, written by `main.ts` to
`/output/entry.txt` — nothing else.

## The joke

> I named my dog 'Stay' — now when I call him, he stays. Best training decision I ever made.

## Why this line

- **Clean pun, first read:** the dog's name *is* the command, so the
  turn lands the moment you hear it — no explaining needed.
- **Fresh inside the tradition:** a dad naming his dog after the one
  command he wants obeyed, not a recycled barnyard or lightbulb setup.
- **Tight, punchline last:** one breath, setup then payoff, 90 characters
  against the 200-character gate.
- **Reads aloud:** a father could deliver it across the dinner table
  and get the groan on "Best training decision I ever made."

## Run

```sh
node main.ts            # writes /output/entry.txt
OUTPUT_DIR=out node main.ts
```
